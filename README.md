# kings-next-game

琉球ゴールデンキングスの「次の試合」を表示する Web ページです。GitHub Pages で公開します。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 「次の試合」ページ（スマホ向け・黒×ゴールドのデザイン） |
| `players.html` | 「選手一覧」ページ |
| `players.json` | 選手一覧（ページはここから読み込みます） |
| `update_players.py` | B.LEAGUE 公式サイトから選手一覧を読み、`players.json` を書き換えるスクリプト |
| `stats.html` | 「成績」ページ |
| `games.json` | 終わった試合のキングスの選手別成績（ページはここから読み込みます） |
| `standings.json` / `update_standings.py` | 地区の順位表と、それを公式サイトから読むスクリプト |
| `calendar.ics` / `update_calendar.py` | カレンダー用の試合予定（結果入り）と、それを作るスクリプト |
| `apple-touch-icon.png` / `favicon.png` | ホーム画面・ブラウザのタブに出るアイコン |
| `update_stats.py` | B.LEAGUE 公式サイトから終わった試合のボックススコアを読み、`games.json` に足すスクリプト |
| `schedule.json` | 試合予定（ページはここから読み込みます） |
| `update_schedule.py` | B.LEAGUE 公式サイトから予定を読み、`schedule.json` を書き換えるスクリプト |
| `.github/workflows/update-schedule.yml` | 上のスクリプトを 1 時間おきに動かす GitHub Actions の設定 |

表示される内容:

- 次の試合の日付・時間・対戦相手・会場・ホーム/アウェイ
- 試合開始までのカウントダウン（試合中は「試合開始から」の経過時間）
- その後の予定の一覧
- B.LEAGUE 公式の試合ページへのリンク
- 試合中は、スコア・クォーター別得点・キングスの選手ごとの得点を速報で表示（試合終了後 3 時間は結果を表示）

終わった試合は自動でとばします。試合開始から 2 時間 30 分たつと「終わった」とみなし、次の試合を表示します（`index.html` の `GAME_LENGTH_MS` で変更できます）。

## 選手一覧

画面左上のタブで「次の試合」と「選手一覧」を切り替えられます。

- 選手一覧には、写真・背番号・名前・ポジションが背番号順に並びます。
- 上のボタンでポジション（PG / SG / SF / PF / C）ごとに絞り込めます。「PG/SG」のような選手は、どちらで絞っても表示されます。
- 選手をタップすると、B.LEAGUE 公式の選手ページが開きます。
- 選手一覧は、試合予定と一緒に 1 時間おきに [公式サイトの選手一覧](https://www.bleague.jp/roster/?tab=1&club=701) から自動で更新されます（変わったときだけ）。
- 写真は公式サイトの画像を直接表示しています（このリポジトリには保存していません）。

## 成績

左上のタブの「成績」で、今シーズンの終わった試合の成績を見られます。

- **シーズン成績**：選手ごとの出場試合数、1 試合平均の得点・リバウンド・アシスト、合計得点。見出しをタップすると並び替えられます。
- **試合ごとの得点**：新しい試合から順に、勝敗・スコアと、得点した選手の得点。
- 選手一覧のカードにも、1 試合平均の得点が出ます。
- 出場時間が 0 の試合（ベンチ入りのみ）は、出場試合数に数えません。
- 1 時間おきの更新で、新しく終わった試合（開始から 3 時間たったもの）だけ読み足します。ボックススコアの数字はページ上の JavaScript で描かれるため、新しい試合があるときだけ GitHub Actions 上でヘッドレスブラウザ（Playwright）を用意して読みます（その回だけ 1〜2 分長くかかります）。

## チケット・ライブ配信

「次の試合」のカードに「チケットを買う」「ライブ配信を見る」ボタンが出ます。

- チケットのリンクは、公式サイトの日程ページの試合カードにあるものをそのまま使っています。
- ライブ配信は、バスケットLIVE の試合ページ（`basketball.mb.softbank.jp/lives/試合番号/`）を開きます。

## 順位表

「成績」タブのいちばん上に、キングスがいる地区の順位表（勝・負・勝率・首位とのゲーム差・連勝/連敗）が出ます。1 時間おきに [公式サイトの順位表](https://www.bleague.jp/standings/?tab=1) から更新されます。

## カレンダーに登録

「次の試合」ページの下の「📅 試合予定をカレンダーに登録」をタップすると、iPhone のカレンダーにキングスの試合が入ります（`webcal://` の照会（購読）として登録されます）。

- これからの試合は「🏀 キングス vs 三遠ネオフェニックス（HOME）」のように入り、チケット・配信のリンクもメモに入ります。
- 終わった試合は「🏀 キングス 85-74 アルバルク東京（勝）」のように結果入りに変わります。
- カレンダーアプリが定期的に読み直すので、新しい予定や結果は自動で反映されます（反映のタイミングはアプリ次第で、数時間〜1日ほどかかることがあります）。
- やめたいときは、カレンダーアプリの「照会したカレンダー」から削除してください。

## ホーム画面のアイコン

ホーム画面に追加すると、黒×ゴールドの「KINGS NEXT GAME」アイコンになります。名前は「キングス」です。すでに追加している場合は、一度削除してから追加し直すと新しいアイコンになります。

## 試合中の速報

試合中のスコアと選手ごとの得点は、[kings-notify](https://github.com/saucerize/kings-notify) の通知ツール（`notifier.py`）が公式サイトを見張りながら送ってくるものを表示しています。

- 通知ツールは試合中、30 秒おきにスコアを、1 分おきにクォーターと選手ごとの得点を読み取っています。
- 読み取った内容は ntfy の公開トピック `kings-live-a38853caea` に送られ、ページは開いている間それを受け取って画面を書き換えます。
- 送信回数の制限があるため、ページへの反映は最大 1 分ほど遅れることがあります（クォーターが変わったときと試合終了はすぐ送ります）。
- 15 分以上更新がないときは、速報を隠していつもの表示に戻ります。
- トピック名を変えたいときは、`index.html` の `LIVE_TOPIC` と、kings-notify の `notifier.py` の `LIVE_TOPIC`（または環境変数 `NTFY_LIVE_TOPIC`）を同じ名前にそろえてください。
- このトピックは誰でも読めます（中身は公開されている試合の情報だけです）。

## 試合予定の自動更新

GitHub Actions が **1 時間おき（毎時 17 分ごろ）** に [B.LEAGUE 公式サイトのキングスの日程](https://www.bleague.jp/schedule/?tab=1&club=701) を読み、`schedule.json` を書き換えます。

- 対戦相手・日時・会場・ホーム/アウェイが変わったときだけ書き換えます（変わらなければ何もしません）。
- 書き換えるとサイトも自動で更新されます（数分かかります）。
- 一度に読むのは、これから行われる試合のうち近い順に 5 試合までです。
- 開始時刻が「未定」の試合は、時刻が決まるまで載りません。
- 会場が読み取れなかったときは、ページに「未定」と表示します。

### すぐに更新したいとき

1. リポジトリの **Actions** タブを開きます。
2. 左の一覧から **試合予定の更新** を選びます。
3. 右側の **Run workflow** → **Run workflow** を押します。

1 分ほどで終わります。実行結果を開くと、公式サイトから読み取った試合の一覧がログに出ています。

### うまく動かないとき

- 実行結果が赤い ✕ になっている場合は、公式サイトのページの形が変わって読み取れなくなった可能性があります。そのあいだ `schedule.json` は前の内容のまま残ります。
- 手で直したいときは `schedule.json` を直接編集してもかまいません。ただし、次の自動更新で上書きされます。
- 自動更新を止めたいときは、**Actions** → **試合予定の更新** → 右上の **…** → **Disable workflow** を押します。

### schedule.json の中身

```json
{
  "datetime": "2026-11-01T15:05:00+09:00",
  "opponent": "千葉ジェッツ",
  "venue": "沖縄サントリーアリーナ",
  "home": true,
  "url": "https://www.bleague.jp/game_detail/?ScheduleKey=…"
}
```

| 項目 | 説明 |
| --- | --- |
| `datetime` | 試合開始日時（日本時間） |
| `opponent` | 対戦相手 |
| `venue` | 会場 |
| `home` | ホームなら `true`、アウェイなら `false` |
| `url` | B.LEAGUE 公式の試合ページ（なくても動きます） |

## GitHub Pages で公開する手順

1. このリポジトリの変更を `main` ブランチに入れます（プルリクエストをマージ）。
2. GitHub でリポジトリを開き、上の **Settings** をクリックします。
3. 左のメニューから **Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** で `main` を選び、その右のフォルダは `/ (root)` のまま **Save** を押します。
6. 1〜2 分待つと、同じ画面の上部に公開 URL が表示されます。
   例: `https://saucerize.github.io/kings-next-game/`
7. URL をスマホで開いて表示を確認します。ホーム画面に追加しておくとアプリのように使えます。

※ 無料プランでは、GitHub Pages はリポジトリが **Public（公開）** の場合のみ使えます。

## 予定を更新するとき

`schedule.json` を編集して `main` ブランチにコミットすると、数分でサイトに反映されます。GitHub の画面上でファイルを開き、鉛筆アイコンから直接編集しても OK です。

## 手元のパソコンで確認したいとき

`index.html` をダブルクリックで開くと、ブラウザの制限で `schedule.json` を読み込めません。次のように簡易サーバーを起動して確認してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。
