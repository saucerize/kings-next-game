# kings-next-game

琉球ゴールデンキングスの「次の試合」を表示する Web ページです。GitHub Pages で公開します。

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体（スマホ向け・黒×ゴールドのデザイン） |
| `schedule.json` | 試合予定（ページはここから読み込みます） |
| `update_schedule.py` | B.LEAGUE 公式サイトから予定を読み、`schedule.json` を書き換えるスクリプト |
| `.github/workflows/update-schedule.yml` | 上のスクリプトを 1 時間おきに動かす GitHub Actions の設定 |

表示される内容:

- 次の試合の日付・時間・対戦相手・会場・ホーム/アウェイ
- 試合開始までのカウントダウン（試合中は「試合開始から」の経過時間）
- その後の予定の一覧
- B.LEAGUE 公式の試合ページへのリンク

終わった試合は自動でとばします。試合開始から 2 時間 30 分たつと「終わった」とみなし、次の試合を表示します（`index.html` の `GAME_LENGTH_MS` で変更できます）。

## 試合予定の自動更新

GitHub Actions が **1 時間おき（毎時 17 分ごろ）** に [B.LEAGUE 公式サイトのキングスの日程](https://www.bleague.jp/schedule/?tab=1&club=701) を読み、`schedule.json` を書き換えます。

- 対戦相手・日時・会場・ホーム/アウェイが変わったときだけ書き換えます（変わらなければ何もしません）。
- 書き換えるとサイトも自動で更新されます（数分かかります）。
- 一度に読むのは、これから行われる試合のうち近い順に 5 試合までです。
- 開始時刻が「未定」の試合は、時刻が決まるまで載りません。
- 会場が読み取れなかったときは、ページに「未定」と表示します。

### すぐに更新したいとき

1. リポジトリの **Actions** タブを開きます。
2. 左の一覧から **試合予定の更新** を選びます。
3. 右側の **Run workflow** → **Run workflow** を押します。

1 分ほどで終わります。実行結果を開くと、公式サイトから読み取った試合の一覧がログに出ています。

### うまく動かないとき

- 実行結果が赤い ✕ になっている場合は、公式サイトのページの形が変わって読み取れなくなった可能性があります。そのあいだ `schedule.json` は前の内容のまま残ります。
- 手で直したいときは `schedule.json` を直接編集してもかまいません。ただし、次の自動更新で上書きされます。
- 自動更新を止めたいときは、**Actions** → **試合予定の更新** → 右上の **…** → **Disable workflow** を押します。

### schedule.json の中身

```json
{
  "datetime": "2026-11-01T15:05:00+09:00",
  "opponent": "千葉ジェッツ",
  "venue": "沖縄サントリーアリーナ",
  "home": true,
  "url": "https://www.bleague.jp/game_detail/?ScheduleKey=…"
}
```

| 項目 | 説明 |
| --- | --- |
| `datetime` | 試合開始日時（日本時間） |
| `opponent` | 対戦相手 |
| `venue` | 会場 |
| `home` | ホームなら `true`、アウェイなら `false` |
| `url` | B.LEAGUE 公式の試合ページ（なくても動きます） |

## GitHub Pages で公開する手順

1. このリポジトリの変更を `main` ブランチに入れます（プルリクエストをマージ）。
2. GitHub でリポジトリを開き、上の **Settings** をクリックします。
3. 左のメニューから **Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** で `main` を選び、その右のフォルダは `/ (root)` のまま **Save** を押します。
6. 1〜2 分待つと、同じ画面の上部に公開 URL が表示されます。
   例: `https://saucerize.github.io/kings-next-game/`
7. URL をスマホで開いて表示を確認します。ホーム画面に追加しておくとアプリのように使えます。

※ 無料プランでは、GitHub Pages はリポジトリが **Public（公開）** の場合のみ使えます。

## 予定を更新するとき

`schedule.json` を編集して `main` ブランチにコミットすると、数分でサイトに反映されます。GitHub の画面上でファイルを開き、鉛筆アイコンから直接編集しても OK です。

## 手元のパソコンで確認したいとき

`index.html` をダブルクリックで開くと、ブラウザの制限で `schedule.json` を読み込めません。次のように簡易サーバーを起動して確認してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。
